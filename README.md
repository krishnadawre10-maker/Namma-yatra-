# 🏛️ Namma Yatra (ನಮ್ಮ ಯಾತ್ರೆ)

> **A localized, browser-based Karnataka travel planner and itinerary generator.**

Namma Yatra is an interactive web application designed to help users discover Karnataka's rich cultural heritage, Western Ghats landscapes, coastal regions, and local traditions. It builds customized routes based on travel time, budget, and personal preferences, while integrating useful Kannada phrases and practical district guidance.

---

## ✨ Key Features

* **Customized Itinerary Generator:** Creates multi-day travel routes across key Karnataka regions (Mysuru, Coorg, Hampi, Badami, Malnad, Coast, etc.) using curated location data.
* **Flexible Preferences:** Tailor trips by pace (relaxed, balanced, packed), offbeat level (famous spots vs. local hidden gems), group size, and specific interests.
* **Cost & Route Breakdown:** Estimates travel distances and breaks down group expenses for stay, food, transport, and entry fees against your target budget.
* **Kannada Corner (`ಕನ್ನಡ ಕಾರ್ನರ್`):** Includes audio playback using browser speech synthesis (`speechSynthesis`) for essential local phrases.
* **Bilingual Support:** Seamlessly switch between **English** and **Kannada** (`ಕನ್ನಡ`).
* **Zero Dependencies:** Fully functional client-side web app—no backend server or external API keys required.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic layout and structured UI design.
* **CSS3:** Responsive grid/flexbox layouts, custom variables, dark/light theme support.
* **Vanilla JavaScript (ES6+):** Dynamic route generation, state management, interactive DOM updates, and web speech synthesis.
